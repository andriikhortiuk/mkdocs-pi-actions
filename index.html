    Introducción Completa a SQL

    SQL (Structured Query Language) es el lenguaje estándar para trabajar con bases de datos relacionales.
    Permite definir estructuras, gestionar permisos y manipular datos de manera eficiente y segura.

    Historia y Evolución de SQL

    SQL fue desarrollado en los años 70 por IBM como parte del proyecto System R. Se convirtió en un estándar ANSI en 1986 y ISO en 1987. Desde entonces, ha evolucionado con versiones como SQL-92, SQL:1999, SQL:2003, etc., incorporando características avanzadas como XML, JSON y funciones de ventana.

    Para más información histórica, visita la historia de SQL en Wikipedia.

    Lenguajes Principales de SQL

    SQL se divide en varios sublenguajes según su función:

    Tipo Descripción Ejemplos de Comandos
    DDL Data Definition Language - Define estructuras CREATE, ALTER, DROP
    DML Data Manipulation Language - Manipula datos SELECT, INSERT, UPDATE, DELETE
    DCL Data Control Language - Controla permisos GRANT, REVOKE
    TCL Transaction Control Language - Gestiona transacciones COMMIT, ROLLBACK, SAVEPOINT

    1. DDL — Data Definition Language

    Se utiliza para crear y modificar objetos de la base de datos como tablas, índices y vistas.

    Ejemplos: - CREATE TABLE - Crea una nueva tabla - ALTER TABLE - Modifica una tabla existente - DROP TABLE - Elimina una tabla - CREATE INDEX - Crea un índice

    2. DCL — Data Control Language

    Controla permisos y autorizaciones de usuarios en la base de datos.

    Ejemplos: - GRANT - Otorga permisos - REVOKE - Revoca permisos

    3. DML — Data Manipulation Language

    Permite trabajar con los datos almacenados: consultar, insertar, modificar y eliminar.

    Ejemplos: - SELECT - Consulta datos - INSERT - Inserta nuevos datos - UPDATE - Modifica datos existentes - DELETE - Elimina datos

    4. TCL — Transaction Control Language

    Gestiona transacciones para asegurar la integridad de los datos.

    Ejemplos: - COMMIT - Confirma una transacción - ROLLBACK - Revierte una transacción - SAVEPOINT - Crea un punto de guardado

    Conceptos Básicos

    Bases de Datos Relacionales

    Una base de datos relacional organiza los datos en tablas relacionadas entre sí. Cada tabla tiene filas (registros) y columnas (campos).

    Tablas, Filas y Columnas

    • Tabla: Estructura que contiene datos relacionados
    • Fila (Registro): Una entrada individual en la tabla
    • Columna (Campo): Un atributo de los datos

    Ejemplo de tabla empleados:

    id nombre apellido salario departamento_id
    1 Juan Pérez 50000 1
    2 María García 60000 2
    3 Carlos López 55000 1

    Claves y Relaciones

    • Clave Primaria (Primary Key): Identifica uniquely cada fila
    • Clave Foránea (Foreign Key): Referencia a una clave primaria de otra tabla
    • Relaciones: Uno a uno, uno a muchos, muchos a muchos

    Ejemplos Prácticos

    Ejemplo de SELECT Básico

    SELECT nombre, salario
FROM empleados
WHERE salario > 50000;

    Ejemplo de JOIN

    SELECT e.nombre, d.nombre_departamento
FROM empleados e
INNER JOIN departamentos d ON e.departamento_id = d.id;

    Ejemplo de INSERT

    INSERT INTO productos (nombre, precio, categoria)
VALUES ('Teclado Mecánico', 89.99, 'Periféricos');

    Ejemplo de UPDATE

    UPDATE empleados
SET salario = salario * 1.05
WHERE departamento_id = 1;

    Ejemplo de DELETE

    DELETE FROM pedidos
WHERE fecha < '2024-01-01' AND estado = 'cancelado';

    Ejemplo de Transacción

    BEGIN;
UPDATE cuentas SET saldo = saldo - 100 WHERE id = 1;
UPDATE cuentas SET saldo = saldo + 100 WHERE id = 2;
COMMIT;

    Funciones y Operadores Comunes

    Funciones Agregadas

    • COUNT() - Cuenta filas
    • SUM() - Suma valores
    • AVG() - Promedio
    • MIN() - Valor mínimo
    • MAX() - Valor máximo

    Funciones de Cadena

    • CONCAT() - Concatena cadenas
    • SUBSTRING() - Extrae subcadena
    • UPPER() / LOWER() - Cambia mayúsculas/minúsculas
    • LENGTH() - Longitud de cadena

    Funciones de Fecha

    • NOW() - Fecha y hora actual
    • DATE() - Parte de fecha
    • DATEDIFF() - Diferencia entre fechas

    Operadores

    • Aritméticos: +, -, *, /
    • Comparación: =, <>, <, >, <=, >=
    • Lógicos: AND, OR, NOT
    • Especiales: LIKE, IN, BETWEEN, IS NULL

    Mejores Prácticas

    1. Usa nombres descriptivos: Para tablas, columnas y variables
    2. Normaliza tus datos: Evita redundancia
    3. Usa índices apropiados: Para mejorar rendimiento
    4. Valida datos: Con restricciones y triggers
    5. Escribe consultas eficientes: Evita subconsultas innecesarias
    6. Usa transacciones: Para operaciones críticas
    7. Documenta tu código: Comentarios y documentación

    Todos los comandos y cláusulas:

    Comando / Cláusula Tipo Descripción
    SELECT DML Consulta datos de una o varias tablas
    DISTINCT DML Elimina filas duplicadas en los resultados
    FROM DML Indica la tabla o tablas a consultar
    WHERE DML Filtra filas según una condición
    GROUP BY DML Agrupa filas para usar funciones agregadas
    HAVING DML Filtra grupos después de agrupar
    ORDER BY DML Ordena los resultados (ASC/DESC)
    LIMIT DML Limita la cantidad de filas devueltas
    OFFSET DML Salta un número de filas antes de mostrar resultados
    INSERT DML Inserta nuevas filas en una tabla
    UPDATE DML Modifica filas existentes
    DELETE DML Elimina filas
    CREATE DDL Crea tablas, vistas u otros objetos
    ALTER DDL Modifica estructuras existentes
    DROP DDL Elimina objetos de la base de datos
    UNION Set Une resultados eliminando duplicados
    UNION ALL Set Une resultados sin eliminar duplicados
    INTERSECT Set Devuelve filas comunes entre consultas
    EXCEPT Set Devuelve filas de la primera consulta que no están en la segunda
    INNER JOIN JOIN Devuelve coincidencias entre tablas
    LEFT JOIN JOIN Devuelve todas las filas de la tabla izquierda y coincidencias de la derecha
    RIGHT JOIN JOIN Devuelve todas las filas de la tabla derecha y coincidencias de la izquierda
    FULL JOIN JOIN Devuelve todas las filas cuando hay coincidencia en cualquiera de las tablas
    CROSS JOIN JOIN Producto cartesiano de tablas
    NATURAL JOIN JOIN Join basado en columnas con nombres iguales
    SELF JOIN JOIN Join de una tabla consigo misma
    CASE Expr Lógica condicional en consultas
    CAST Expr Convierte tipos de datos
    COALESCE Expr Devuelve el primer valor no nulo
    NULLIF Expr Devuelve NULL si dos expresiones son iguales
    EXTRACT Date Extrae parte de una fecha
    DATEADD Date Añade intervalo a fecha (SQL Server)
    DATE_PART Date Extrae parte de fecha (PostgreSQL)
    ROW_NUMBER Window Asigna números de fila
    RANK Window Asigna rangos
    DENSE_RANK Window Asigna rangos densos
    LAG Window Accede a fila anterior
    LEAD Window Accede a fila siguiente
    SUM OVER Window Suma acumulada
    AVG OVER Window Promedio móvil
    COUNT OVER Window Conteo en ventana
    WITH (CTE) CTE Expresiones de tabla comunes
    RECURSIVE CTE CTEs recursivas
    GRANT DCL Otorga permisos
    REVOKE DCL Revoca permisos
    COMMIT TCL Confirma transacción
    ROLLBACK TCL Revierte transacción
    SAVEPOINT TCL Punto de guardado en transacción
    BEGIN TCL Inicia transacción
    START TRANSACTION TCL Inicia transacción
    SET TRANSACTION TCL Establece propiedades de transacción
    CREATE VIEW DDL Crea vista
    CREATE INDEX DDL Crea índice
    CREATE TRIGGER DDL Crea trigger
    CREATE PROCEDURE DDL Crea procedimiento almacenado
    CREATE FUNCTION DDL Crea función
    ALTER TABLE DDL Modifica tabla
    ALTER VIEW DDL Modifica vista
    DROP TABLE DDL Elimina tabla
    DROP VIEW DDL Elimina vista
    DROP INDEX DDL Elimina índice
    TRUNCATE TABLE DDL Vacía tabla rápidamente
    COMMENT ON DDL Añade comentario a objeto
    ANALYZE Util Actualiza estadísticas (PostgreSQL)
    EXPLAIN Util Muestra plan de ejecución
    SHOW Util Muestra información del sistema (MySQL)
    DESCRIBE Util Describe estructura de tabla
    INFORMATION_SCHEMA Meta Vistas del sistema para metadatos

    Conclusión

    SQL es fundamental para cualquier profesional que trabaje con datos. Desde consultas simples hasta análisis complejos, SQL proporciona las herramientas necesarias para gestionar información de manera efectiva. Comienza con los conceptos básicos y practica regularmente para dominar este poderoso lenguaje.
