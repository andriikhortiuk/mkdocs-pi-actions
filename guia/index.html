    Guía Completa de Uso de SQL

    Introducción a SQL

    SQL (Structured Query Language) es el lenguaje estándar utilizado para gestionar y manipular bases de datos relacionales. Fue desarrollado en los años 70 por IBM y se ha convertido en el estándar de facto para sistemas de gestión de bases de datos (DBMS) como MySQL, PostgreSQL, Oracle, SQL Server, entre otros.

    SQL permite realizar operaciones como consultar datos, insertar nuevos registros, actualizar información existente y eliminar datos. Es esencial para cualquier desarrollador, analista de datos o administrador de bases de datos.

    Para más información, visita la página oficial de SQL en W3Schools.

    Conceptos Básicos

    Bases de Datos y Tablas

    Una base de datos es una colección organizada de datos. Dentro de una base de datos, los datos se almacenan en tablas, que consisten en filas (registros) y columnas (campos).

    Ejemplo de tabla empleados:

    id nombre apellido salario departamento
    1 Juan Pérez 50000 Ventas
    2 María García 60000 IT
    3 Carlos López 55000 Marketing

    Tipos de Datos

    SQL soporta varios tipos de datos:

    • VARCHAR(n): Cadena de caracteres de longitud variable
    • INT: Números enteros
    • DECIMAL(p,s): Números decimales
    • DATE: Fechas
    • BOOLEAN: Valores verdadero/falso
    • TEXT: Texto largo
    • BLOB: Datos binarios

    Para una referencia completa, consulta la documentación de tipos de datos en PostgreSQL.

    Consultas Básicas (SELECT)

    La instrucción SELECT se utiliza para recuperar datos de una o más tablas.

    Sintaxis Básica

    SELECT columna1, columna2, ...
FROM tabla
WHERE condición;

    Ejemplo:

    SELECT nombre, apellido
FROM empleados
WHERE salario > 50000;

    Operadores de Comparación

    Operador Descripción Ejemplo
    = Igual a salario = 50000
    <> o != Diferente de departamento <> 'IT'
    > Mayor que edad > 30
    < Menor que salario < 60000
    >= Mayor o igual experiencia >= 5
    <= Menor o igual puntuación <= 85
    BETWEEN Entre dos valores salario BETWEEN 40000 AND 60000
    IN En una lista departamento IN ('IT', 'Ventas')
    LIKE Patrón de texto nombre LIKE 'J%'
    IS NULL Es nulo fecha_nacimiento IS NULL

    Operadores Lógicos

    • AND: Ambas condiciones deben ser verdaderas
    • OR: Al menos una condición debe ser verdadera
    • NOT: Niega la condición

    Ejemplo:

    SELECT *
FROM empleados
WHERE departamento = 'IT' AND salario > 55000;

    Ordenamiento y Limitación (ORDER BY, LIMIT)

    ORDER BY

    Ordena los resultados por una o más columnas.

    SELECT nombre, salario
FROM empleados
ORDER BY salario DESC, nombre ASC;

    LIMIT y OFFSET

    Limita el número de filas devueltas y permite paginación.

    SELECT nombre, salario
FROM empleados
ORDER BY salario DESC
LIMIT 5 OFFSET 10;

    En SQL Server se usa TOP y OFFSET FETCH:

    SELECT TOP 5 nombre, salario
FROM empleados
ORDER BY salario DESC;

-- Para paginación
SELECT nombre, salario
FROM empleados
ORDER BY salario DESC
OFFSET 10 ROWS FETCH NEXT 5 ROWS ONLY;

    Funciones Agregadas

    SQL proporciona funciones para realizar cálculos en grupos de filas.

    Funciones Principales

    • COUNT(): Cuenta el número de filas
    • SUM(): Suma los valores
    • AVG(): Calcula el promedio
    • MIN(): Encuentra el valor mínimo
    • MAX(): Encuentra el valor máximo

    Ejemplo:

    SELECT departamento, COUNT(*) as num_empleados, AVG(salario) as salario_promedio
FROM empleados
GROUP BY departamento;

    GROUP BY y HAVING

    GROUP BY agrupa filas que tienen los mismos valores en columnas especificadas.

    HAVING filtra grupos después de la agrupación.

    SELECT departamento, AVG(salario)
FROM empleados
GROUP BY departamento
HAVING AVG(salario) > 50000;

    CASE Statements

    La expresión CASE permite lógica condicional en consultas SQL.

    Sintaxis

    CASE
    WHEN condición1 THEN resultado1
    WHEN condición2 THEN resultado2
    ELSE resultado_default
END

    Ejemplo:

    SELECT nombre,
       CASE
           WHEN salario > 60000 THEN 'Alto'
           WHEN salario > 40000 THEN 'Medio'
           ELSE 'Bajo'
       END as nivel_salario
FROM empleados;

    Joins (Uniones)

    Los joins permiten combinar filas de dos o más tablas basadas en una condición relacionada.

    Tipos de Joins

    1. INNER JOIN: Devuelve filas que tienen coincidencias en ambas tablas
    2. LEFT JOIN: Devuelve todas las filas de la tabla izquierda y las coincidentes de la derecha
    3. RIGHT JOIN: Devuelve todas las filas de la tabla derecha y las coincidentes de la izquierda
    4. FULL OUTER JOIN: Devuelve todas las filas cuando hay una coincidencia en cualquiera de las tablas
    5. CROSS JOIN: Producto cartesiano de las tablas

    Ejemplos

    Supongamos tablas empleados y departamentos:

    -- INNER JOIN
SELECT e.nombre, d.nombre_departamento
FROM empleados e
INNER JOIN departamentos d ON e.id_departamento = d.id;

-- LEFT JOIN
SELECT e.nombre, d.nombre_departamento
FROM empleados e
LEFT JOIN departamentos d ON e.id_departamento = d.id;

-- CROSS JOIN
SELECT e.nombre, d.nombre_departamento
FROM empleados e
CROSS JOIN departamentos d;

    Para más detalles sobre joins, visita SQL Joins en W3Schools.

    Subconsultas

    Una subconsulta es una consulta anidada dentro de otra consulta.

    Tipos

    • Subconsulta escalar: Devuelve un solo valor
    • Subconsulta de fila: Devuelve una fila
    • Subconsulta de tabla: Devuelve una tabla

    Ejemplo:

    SELECT nombre
FROM empleados
WHERE salario > (SELECT AVG(salario) FROM empleados);

    Common Table Expressions (CTEs)

    Las CTEs permiten definir consultas temporales que pueden ser referenciadas en la consulta principal.

    Sintaxis

    WITH nombre_cte AS (
    SELECT ...
)
SELECT ... FROM nombre_cte;

    Ejemplo:

    WITH empleados_altos AS (
    SELECT nombre, salario
    FROM empleados
    WHERE salario > 50000
)
SELECT nombre, salario * 1.1 as salario_incrementado
FROM empleados_altos;

    Funciones de Ventana (Window Functions)

    Las funciones de ventana realizan cálculos sobre un conjunto de filas relacionadas.

    Ejemplos

    • ROW_NUMBER(): Asigna números de fila
    • RANK(): Asigna rangos
    • SUM() OVER(): Suma acumulada
    SELECT nombre, salario,
       ROW_NUMBER() OVER (ORDER BY salario DESC) as ranking,
       SUM(salario) OVER (PARTITION BY departamento ORDER BY salario) as suma_acumulada
FROM empleados;

    Inserción de Datos (INSERT)

    Sintaxis

    INSERT INTO tabla (columna1, columna2, ...)
VALUES (valor1, valor2, ...);

    Ejemplo:

    INSERT INTO empleados (nombre, apellido, salario, departamento)
VALUES ('Ana', 'Martínez', 52000, 'Recursos Humanos');

    Insertar Múltiples Filas

    INSERT INTO empleados (nombre, apellido, salario, departamento)
VALUES 
('Pedro', 'Sánchez', 48000, 'Ventas'),
('Laura', 'Gómez', 57000, 'IT');

    INSERT con SELECT

    INSERT INTO empleados_backup
SELECT * FROM empleados WHERE departamento = 'IT';

    Actualización de Datos (UPDATE)

    Sintaxis

    UPDATE tabla
SET columna1 = valor1, columna2 = valor2, ...
WHERE condición;

    Ejemplo:

    UPDATE empleados
SET salario = salario * 1.1
WHERE departamento = 'IT';

    Eliminación de Datos (DELETE)

    Sintaxis

    DELETE FROM tabla
WHERE condición;

    Ejemplo:

    DELETE FROM empleados
WHERE id = 3;

    Creación de Tablas (CREATE TABLE)

    Sintaxis Básica

    CREATE TABLE tabla (
    columna1 tipo_dato restricciones,
    columna2 tipo_dato restricciones,
    ...
);

    Ejemplo:

    CREATE TABLE empleados (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nombre VARCHAR(50) NOT NULL,
    apellido VARCHAR(50) NOT NULL,
    salario DECIMAL(10,2),
    departamento VARCHAR(50),
    fecha_contratacion DATE DEFAULT CURRENT_DATE
);

    Restricciones

    • PRIMARY KEY: Identificador único
    • FOREIGN KEY: Referencia a otra tabla
    • NOT NULL: No permite valores nulos
    • UNIQUE: Valores únicos
    • DEFAULT: Valor por defecto
    • CHECK: Condición que debe cumplirse

    Índices

    Los índices mejoran el rendimiento de las consultas al permitir búsquedas más rápidas.

    Creación de Índices

    CREATE INDEX idx_nombre ON empleados (nombre);
CREATE UNIQUE INDEX idx_email ON empleados (email);

    Tipos de Índices

    • B-Tree: Para búsquedas de igualdad y rango
    • Hash: Para búsquedas de igualdad exacta
    • Bitmap: Para columnas con pocos valores distintos
    • Full-text: Para búsqueda de texto

    Para más información sobre índices, consulta la documentación de PostgreSQL sobre índices.

    Transacciones

    Las transacciones permiten ejecutar múltiples operaciones como una unidad atómica.

    Propiedades ACID

    • Atomicity: Todo o nada
    • Consistency: Mantiene la integridad de los datos
    • Isolation: Las transacciones no interfieren entre sí
    • Durability: Los cambios son permanentes

    Sintaxis

    BEGIN TRANSACTION;
-- Operaciones
COMMIT;
-- o ROLLBACK en caso de error

    Ejemplo:

    BEGIN;
UPDATE cuentas SET saldo = saldo - 100 WHERE id = 1;
UPDATE cuentas SET saldo = saldo + 100 WHERE id = 2;
COMMIT;

    Vistas

    Las vistas son consultas almacenadas que se pueden tratar como tablas.

    Creación

    CREATE VIEW vista_empleados_it AS
SELECT nombre, apellido, salario
FROM empleados
WHERE departamento = 'IT';

    Uso

    SELECT * FROM vista_empleados_it;

    Procedimientos Almacenados

    Los procedimientos almacenados son programas SQL guardados en la base de datos.

    Ejemplo en SQL Server

    CREATE PROCEDURE sp_actualizar_salario
    @id_empleado INT,
    @nuevo_salario DECIMAL(10,2)
AS
BEGIN
    UPDATE empleados
    SET salario = @nuevo_salario
    WHERE id = @id_empleado;
END;

    Llamada

    EXEC sp_actualizar_salario 1, 55000;

    Triggers

    Los triggers son procedimientos que se ejecutan automáticamente cuando ocurre un evento en la base de datos.

    Ejemplo

    CREATE TRIGGER trg_actualizar_fecha_modificacion
AFTER UPDATE ON empleados
FOR EACH ROW
BEGIN
    UPDATE empleados
    SET fecha_modificacion = NOW()
    WHERE id = NEW.id;
END;

    Soporte JSON en SQL

    Muchos DBMS modernos soportan JSON para datos semi-estructurados.

    Ejemplo en PostgreSQL

    CREATE TABLE productos (
    id SERIAL PRIMARY KEY,
    datos JSONB
);

INSERT INTO productos (datos) VALUES ('{"nombre": "Teclado", "precio": 25.99}');

SELECT datos->>'nombre' as nombre FROM productos;

    Optimización de Consultas

    Consejos

    1. Usa índices apropiados
    2. Evita SELECT *
    3. Usa JOINs en lugar de subconsultas cuando sea posible
    4. Limita los resultados con WHERE lo antes posible
    5. Usa EXPLAIN para analizar el plan de ejecución
    6. Considera la normalización de datos
    7. Usa particionamiento para tablas grandes

    Ejemplo de EXPLAIN

    EXPLAIN SELECT nombre, salario
FROM empleados
WHERE departamento = 'IT';

    Seguridad en SQL

    Inyección SQL

    La inyección SQL es un ataque donde se inserta código malicioso en consultas SQL.

    Prevención

    • Usa prepared statements
    • Valida y sanitiza entradas
    • Usa ORM (Object-Relational Mapping)
    • Limita permisos de usuarios

    Ejemplo de prepared statement en PHP:

    $stmt = $pdo->prepare("SELECT * FROM usuarios WHERE email = ?");
$stmt->execute([$email]);

    Para más sobre seguridad SQL, visita OWASP SQL Injection.

    • PostgreSQL: Arrays, JSON, PostGIS para GIS
    • SQL Server: T-SQL, Integration Services
    • Oracle: PL/SQL, Advanced Analytics
